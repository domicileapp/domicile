# Security

If you find a security vulnerability in Domicile, please report it privately rather than opening a public issue.

You can report it through GitHub:

[Report a vulnerability](https://github.com/domicileapp/domicile/security/advisories/new)

I'll do my best to respond within 7 days and keep you updated while I investigate and fix the issue.

Please give me at least 30 days to address a vulnerability before publicly disclosing it. If I need more time, I'll work with you on a reasonable disclosure timeline.

Thanks in advance!
